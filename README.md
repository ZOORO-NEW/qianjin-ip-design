# Qianjin IP Design System | 前进IP形象设计系统

> **6大风格 × 8维设计规则 × 跨风格通用法则**。让IP形象从"好看"到"有灵魂"。

## 覆盖风格 | Style Categories

| 风格 | 核心气质 | 代表案例 |
|------|---------|---------|
| 🧸 **萌系** | 无害感、幼态、柔软 | Hello Kitty、Line Friends、三丽鸥 |
| 😎 **潮酷系** | 态度感、拽、不羁 | KAWS、BE@RBRICK、村上隆 |
| 🏮 **国风系** | 文化感、内敛、风骨 | 故宫猫、敦煌IP、哪吒 |
| 🔷 **极简系** | 符号感、高辨识度 | 米其林轮胎人、Twitter蓝鸟 |
| 🎭 **暗黑系** | 反叛感、神秘、力量 | Corpse Bride、暗黑潮玩 |
| 🌿 **治愈系** | 放松感、温暖、安全 | 松弛熊、黄油小狗 |

## 每套风格包含

每个风格都有8个完整设计维度：
1. **头部比例规范** — 脸型、额头、耳朵定位、头部曲率
2. **身体比例规范** — 头身比、肩宽、四肢、重心
3. **五官/面部设计** — 眼/鼻/嘴/眉的具体参数
4. **色彩体系** — 主色/辅色/点缀色/禁忌色
5. **轮廓与剪影** — 外轮廓规则、剪影测试标准
6. **记忆点植入** — 5种记忆点植入手法+公式
7. **情绪表达规则** — 6种基本情绪的五官变形公式+量化公式
8. **气质塑造公式** — 量化公式+验证标准
